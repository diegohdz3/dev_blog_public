/ overview

What is BakingDesk?

BakingDesk is a full-stack bakery management system designed to streamline daily operations for small bakeries. From inventory tracking to order management, the application covers the core needs of a bakery business in a clean, intuitive interface.

This was my first integrated project for my university coursework — a project where I had to combine everything I'd learned about backend development, database design, and frontend implementation into a single, cohesive product. I took the lead on backend architecture and proposed the visual design direction for the team.

/ timeline

The development process.

Phase 01

Planning & Research

Defined the project scope, researched bakery workflows, designed the database schema, and created initial wireframes for the user interface.

Phase 02

Backend Architecture

Built the server-side logic, API endpoints, database connections, and authentication system. This was the core of my contribution to the team.

Phase 03

Frontend & Design

Proposed and implemented the visual design direction. Connected the frontend with backend APIs and ensured a smooth user experience across the application.

Phase 04

Testing & Delivery

Final testing, bug fixes, documentation, and project presentation. Successfully delivered as a complete, functional system.

/ challenges

What I learned.

Backend Architecture

Learning to structure a real backend from scratch — handling routes, controllers, and database queries in a way that actually scales was one of the biggest hurdles I faced.

Team Collaboration

Working in a team taught me how to communicate technical decisions, manage code conflicts, and align everyone toward a shared vision — skills that go beyond just writing code.

Design Decisions

Proposing the design for the whole team was nerve-wracking. I had to balance aesthetics with usability and make sure the interface was intuitive for real bakery workflows.
